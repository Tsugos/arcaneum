# PROMPT_PIPELINE

## Назначение

Prompt Pipeline — одна из важнейших подсистем Arcaneum.

Она отвечает за построение окончательного контекста, который передается языковой модели.

Ни одна другая подсистема не должна самостоятельно формировать финальный промпт.

---

# Основная идея

Prompt Pipeline представляет собой конвейер независимых этапов.

Каждый этап получает контекст, дополняет его и передает следующему.

Это позволяет отключать, заменять или расширять отдельные части без изменения остальных.

---

# Стандартная последовательность

1. System Instructions
2. User Persona
3. Active Persona
4. Session Rules
5. Lorebook
6. Long-Term Memory
7. Short-Term Memory
8. Summary
9. Author Notes
10. Dynamic Context
11. Current Conversation
12. User Message
13. Provider Adapter

Каждый этап является самостоятельным модулем.

---

# Принципы

Prompt Pipeline не знает, какая модель будет использоваться.

Он формирует нейтральное представление контекста.

Адаптация под особенности конкретного AI происходит только на последнем этапе через Provider Adapter.

---

# Приоритет

Если различные источники содержат противоречивую информацию, используется следующая иерархия:

1. System Instructions.
2. Session Rules.
3. Active Persona.
4. Lorebook.
5. Long-Term Memory.
6. Summary.
7. Current Conversation.
8. User Message.

Изменение этого порядка должно выполняться через настройки пользователя.

---

# Расширяемость

Новые этапы могут быть добавлены через систему плагинов.

Существующие этапы не должны изменяться ради поддержки новых возможностей.

---

# Диагностика

Pipeline обязан поддерживать режим отладки.

Пользователь должен иметь возможность увидеть:

- итоговый контекст;
- вклад каждого этапа;
- количество токенов;
- итоговый размер запроса.

Это особенно важно для оптимизации RP и понимания поведения моделей.
