# DOCK_LAYOUT

## Назначение

Dock Layout отвечает за расположение всех элементов интерфейса.

---

# Панели

Любая подсистема отображается как Dock Panel.

Например:

- Chat
- Persona
- Story
- Memory
- Lorebook
- Images
- AI Settings
- Prompt Debugger

---

# Возможности

Каждую панель можно:

- закрепить;
- открепить;
- свернуть;
- закрыть;
- вынести в отдельную вкладку;
- изменить размер.

---

# Layout

Расположение панелей автоматически сохраняется внутри Workspace.

Разные Workspace могут иметь собственные макеты.

---

# Presets

Пользователь может создавать собственные Layout Presets.

Например:

Roleplay.

↓

Writing.

↓

Character Creation.

↓

Image Generation.

↓

Debug.

Каждый пресет восстанавливает расположение всех панелей.
