# PERSONA_EDITOR

## Назначение

Persona Editor является главным инструментом создания и настройки Persona.

Редактор должен скрывать внутреннюю структуру данных и предоставлять пользователю интуитивный интерфейс.

---

# Основной принцип

Пользователь работает с образом персонажа, а не с JSON.

Все технические детали скрываются системой.

---

# Интерфейс

Редактор разделён на логические разделы.

Каждый раздел отвечает за отдельный аспект Persona.

---

# Основные разделы

- Overview
- Identity
- Personality
- Appearance
- Behaviour
- Dialogue
- World
- Relationships
- Assets
- Prompt
- Advanced

---

# Автосохранение

Любое изменение сохраняется автоматически.

Редактор не использует кнопку Save.

---

# Предпросмотр

Пользователь может в любой момент увидеть, как Persona выглядит с точки зрения Prompt Pipeline.

Это позволяет быстро находить ошибки.
