# MEMORY_ENGINE (Part II)

## Типы памяти

Arcaneum рассматривает память как совокупность различных видов знаний, а не единое хранилище.

Каждый тип памяти имеет собственную цель и собственные правила обработки.

---

## Short-Term Memory

Содержит события последних сообщений.

Используется для поддержания непрерывности текущего взаимодействия.

Автоматически обновляется после каждой генерации.

---

## Long-Term Memory

Содержит информацию, которая должна переживать отдельные сообщения и длительные промежутки времени.

Используется при формировании общего понимания истории.

---

## Episodic Memory

Хранит воспоминания о конкретных событиях.

Примеры:

- первая встреча персонажей;
- совместная победа;
- предательство;
- гибель союзника;
- заключение договора.

Эпизоды являются самостоятельными объектами и могут ссылаться друг на друга.

---

## Semantic Memory

Хранит факты.

Например:

- возраст персонажа;
- профессия;
- место проживания;
- отношения;
- способности;
- предпочтения.

Факты существуют независимо от событий.

---

## Relationship Memory

Отвечает исключительно за отношения между сущностями.

Например:

Пользователь доверяет персонажу.

Персонаж испытывает ревность.

Два NPC являются родственниками.

Данная память должна использоваться отдельно от остальных.

---

## Emotional Memory

Хранит эмоциональную окраску значимых событий.

Например:

Сильный страх.

Радость.

Обида.

Ненависть.

Вдохновение.

Эмоции не являются фактами.

Они являются контекстом, который влияет на последующее поведение Persona.

---

## User Memory

Хранит информацию непосредственно о пользователе.

Примеры:

- любимый стиль RP;
- предпочтительный язык;
- любимые персонажи;
- постоянные инструкции.

Эта память принадлежит пользователю, а не конкретной Session.

---

## Session Memory

Хранит информацию, актуальную только внутри текущей Session.

После завершения Session она может быть:

- удалена;
- архивирована;
- объединена с Long-Term Memory.

Это определяется настройками пользователя.
