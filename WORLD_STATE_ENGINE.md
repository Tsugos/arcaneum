# WORLD_STATE_ENGINE

## Почему этот модуль существует

Большинство RP-клиентов рассматривают мир как неизменяемый набор знаний.

Это приводит к тому, что события не оказывают долгосрочного влияния.

Arcaneum вводит отдельную систему состояния мира.

---

# Назначение

World State Engine хранит текущее состояние игровой вселенной.

Он отвечает на вопрос:

"Как выглядит мир прямо сейчас?"

---

# Что может храниться

Например:

Политическая ситуация.

Время суток.

Погода.

Разрушенные здания.

Живые персонажи.

Экономическое состояние.

Военные конфликты.

Активные квесты.

Эпидемии.

Магические аномалии.

Любые динамические изменения.

---

# Отличие от Lorebook

Lorebook описывает знания о мире.

World State описывает текущее состояние мира.

Например:

Lorebook:

"Столица государства называется Альтар."

World State:

"Альтар разрушен после осады."

---

# Изменяемость

World State постоянно обновляется по мере развития истории.

Он не является статичной базой знаний.

---

# История изменений

Каждое изменение сохраняется.

Это позволяет:

- восстановить прошлое состояние;
- анализировать развитие истории;
- строить временную линию событий.

---

# Использование

Prompt Pipeline самостоятельно определяет, какие элементы World State необходимо включить в текущий контекст.

Это позволяет модели учитывать последствия предыдущих действий без необходимости повторно описывать весь мир.
