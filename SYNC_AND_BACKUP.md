# SYNC_AND_BACKUP

## Назначение

Arcaneum не предполагает обязательную облачную синхронизацию.

Однако пользователь должен иметь надёжные средства сохранения своих данных.

---

# Основные режимы

- автоматическое резервное копирование;
- ручное резервное копирование;
- экспорт Workspace;
- локальные снимки (Snapshots).

---

# Snapshots

Snapshot представляет собой мгновенное состояние Workspace.

Пользователь может вернуться к любому сохранённому состоянию.

---

# История

Система хранит ограниченное количество автоматических снимков.

Количество определяется настройками пользователя.

---

# Проверка целостности

Перед восстановлением резервной копии выполняется проверка контрольных сумм и структуры данных.

---

# Будущее

Архитектура должна позволять в дальнейшем добавить синхронизацию через сторонние сервисы (например, GitHub, WebDAV, облачные хранилища) без изменения остальных подсистем.

Такие возможности являются расширениями и не входят в ядро проекта.
