# ENTITY_SYSTEM

## Почему Entity

Внутри Arcaneum существует множество различных объектов:

- Persona;
- Session;
- Message;
- Memory;
- Lorebook Entry;
- Story Event;
- Asset;
- Plugin.

Несмотря на различия, все они обладают общими свойствами.

Entity System определяет единый контракт для всех сущностей.

---

# Базовые свойства

Каждая Entity содержит:

- ID;
- Type;
- Version;
- CreatedAt;
- UpdatedAt;
- Tags;
- Metadata.

---

# Теги

Любая сущность может иметь произвольное количество тегов.

Теги используются для:

- поиска;
- фильтрации;
- автоматизации;
- группировки.

---

# Метаданные

Метаданные не влияют на бизнес-логику.

Они используются для хранения дополнительной информации.

---

# Родительские связи

Entity могут ссылаться друг на друга.

Например:

Message → Session.

Session → Story.

Persona → Asset.

Memory → Story Event.

Связи должны быть однонаправленными, если двусторонняя связь не требуется бизнес-логикой.

---

# Расширяемость

Любой Plugin может добавлять собственные Entity.

Ядро должно безопасно работать с неизвестными типами, пока они соответствуют базовому контракту.
