# SYSTEM_MODULES

## Назначение

Этот документ определяет все крупные подсистемы Arcaneum.

Каждая подсистема должна быть полностью независимой.

---

# Core

Ядро приложения.

Содержит:

- Dependency Injection;
- Event Bus;
- Service Registry;
- Plugin Loader;
- Configuration.

Core не знает о реализации модулей.

---

# Character System

Управляет:

- персонажами;
- импортом;
- экспортом;
- версиями;
- тегами.

---

# Chat Engine

Отвечает за:

- переписки;
- сообщения;
- очереди;
- историю.

---

# Prompt Engine

Формирует Prompt Context.

Он ничего не генерирует.

Он только собирает данные.

---

# Memory Engine

Управляет:

- краткосрочной памятью;
- долгосрочной памятью;
- суммаризацией;
- поиском;
- выборкой контекста.

---

# Lorebook Engine

Управляет:

- знаниями мира;
- автоматическим поиском;
- приоритетами;
- конфликтами записей.

---

# Model Manager

Хранит:

- список моделей;
- возможности моделей;
- рейтинги;
- фильтрацию;
- совместимость.

---

# AI Provider Manager

Управляет:

- подключением провайдеров;
- переключением;
- очередями;
- отказоустойчивостью.

---

# Image Engine

Работает с генерацией изображений.

---

# Voice Engine

Работает с голосовыми функциями.

---

# Storage Manager

Работает исключительно с сохранением данных.

---

# Backup Manager

Создает резервные копии Workspace.

---

# Theme Manager

Управляет оформлением.

---

# Settings Manager

Управляет настройками приложения.

---

# Plugin Manager

Загружает плагины.

Не знает их внутреннего устройства.

---

# Notification Manager

Показывает:

- ошибки;
- предупреждения;
- прогресс;
- уведомления.

---

# Telemetry (локальная)

Собирает локальную статистику работы приложения.

Не отправляет данные в интернет без явного разрешения пользователя.
