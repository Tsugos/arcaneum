# EXPRESSION_SYSTEM

## Назначение

Expression System позволяет Persona использовать различные визуальные состояния.

---

# Expression

Выражение включает:

- изображение;
- название;
- описание;
- условия использования.

---

# Примеры

Neutral.

Happy.

Sad.

Angry.

Embarrassed.

Surprised.

Sleepy.

Serious.

---

# Автоматический выбор

Во время генерации система может автоматически выбирать подходящее выражение лица.

Основанием могут служить:

- эмоции;
- настроение;
- сюжет;
- пользовательские правила.

---

# Ручной выбор

Пользователь всегда может выбрать выражение самостоятельно.

Автоматическая система не должна ограничивать ручное управление.

---

# Совместимость

Expression System является необязательной подсистемой.

Persona без изображений остаётся полностью работоспособной.
