# MEMORY_RETRIEVAL

## Назначение

Даже идеальная память бесполезна, если система не умеет выбирать нужную информацию.

Memory Retrieval отвечает за поиск наиболее релевантных воспоминаний.

---

# Главный принцип

Никогда не отправлять модели всю память.

Передавать только информацию, полезную в текущем контексте.

---

# Этапы выбора

При каждом сообщении система выполняет:

1. Анализ нового сообщения.
2. Определение ключевых тем.
3. Поиск связанных событий.
4. Поиск связанных персонажей.
5. Поиск связанных фактов.
6. Ранжирование результатов.
7. Ограничение по бюджету токенов.
8. Передача Prompt Pipeline.

---

# Источники релевантности

При расчёте важности учитываются:

- совпадение темы;
- совпадение участников;
- совпадение места;
- совпадение времени;
- эмоциональная близость;
- пользовательские закрепления;
- частота использования.

---

# Memory Score

Каждое воспоминание получает числовой рейтинг.

На него влияют:

- важность;
- актуальность;
- свежесть;
- пользовательские настройки;
- ручное закрепление.

---

# Закрепление

Пользователь может отметить воспоминание как:

Pinned.

Такие записи имеют максимальный приоритет.

---

# Автоматическое забывание

Система не обязана удалять старые записи.

Она может постепенно уменьшать их приоритет.

Физическое удаление выполняется только по решению пользователя.

---

# Прозрачность

Пользователь должен иметь возможность увидеть:

- почему конкретное воспоминание было выбрано;
- какой рейтинг оно получило;
- какие записи были отброшены.

Это необходимо для отладки поведения модели.
