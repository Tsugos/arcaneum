# RULE_ENGINE

## Назначение

Rule Engine управляет всеми правилами, действующими в рамках Session.

Правила существуют независимо от персонажей, памяти и модели.

---

# Примеры правил

Запрет нарушать канон.

Не использовать современную лексику.

Все действия происходят от третьего лица.

Персонажи не знают мысли друг друга.

Боевая система основана на бросках кубиков.

Запрещено описывать действия пользователя.

Любое правило может быть включено или отключено.

---

# Категории

Rule Engine поддерживает:

- Global Rules;
- Workspace Rules;
- Session Rules;
- Persona Rules;
- Temporary Rules.

---

# Приоритет

Если правила конфликтуют, используется следующая иерархия:

1. Session.
2. Persona.
3. Workspace.
4. Global.

---

# Формат

Каждое правило должно содержать:

- идентификатор;
- описание;
- категорию;
- приоритет;
- условия активации.

---

# Динамические правила

Некоторые правила могут активироваться автоматически.

Например:

Во время боя.

Во время диалога.

Во сне персонажа.

После определённого события.

---

# Использование

Prompt Pipeline самостоятельно выбирает только активные правила.

Неактивные правила не расходуют контекст.
