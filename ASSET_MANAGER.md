# ASSET_MANAGER

## Назначение

Asset Manager управляет всеми бинарными ресурсами проекта.

---

# Поддерживаемые типы

- аватары;
- изображения;
- выражения лица;
- фоновые изображения;
- голосовые файлы;
- документы;
- резервные копии;
- пользовательские вложения.

---

# Единая модель

Каждый ресурс описывается одинаково:

- ID;
- тип;
- источник;
- размер;
- контрольная сумма;
- дата создания;
- владелец;
- ссылки на использующие сущности.

---

# Дедупликация

Если несколько Persona используют один и тот же файл, он хранится один раз.

---

# Превью

Для изображений должны автоматически создаваться уменьшенные копии (thumbnail), чтобы интерфейс оставался отзывчивым.

---

# Очистка

Удаление ресурса допускается только после проверки, что на него не ссылаются другие сущности.

---

# Импорт

При импорте Persona Package или Workspace все ресурсы автоматически регистрируются в Asset Manager.
