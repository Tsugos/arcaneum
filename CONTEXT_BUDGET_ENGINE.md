# CONTEXT_BUDGET_ENGINE

## Проблема

Контекст языковой модели ограничен.

Количество доступных токенов всегда конечно.

Поэтому Arcaneum рассматривает контекст как ограниченный ресурс.

---

# Назначение

Context Budget Engine управляет распределением доступного количества токенов между всеми подсистемами.

---

# Источники контекста

Контекст формируется из следующих компонентов:

- System Instructions;
- Rules;
- Persona;
- World State;
- Lorebook;
- Long-Term Memory;
- Episodic Memory;
- Summary;
- Current Conversation;
- User Message.

---

# Бюджет

Каждый источник получает собственный бюджет.

Пример:

System — 8%.

Persona — 15%.

Lorebook — 20%.

Memory — 20%.

Conversation — 25%.

Summary — 7%.

Rules — 5%.

Распределение должно быть полностью настраиваемым.

---

# Приоритет

При нехватке места Context Budget Engine начинает сокращать менее важные источники.

Например:

Summary.

↓

Lorebook.

↓

Memory.

↓

Conversation.

System Instructions сокращаются только в исключительных случаях.

---

# Отчёт

Пользователь должен видеть:

- сколько токенов занял каждый блок;
- итоговый размер запроса;
- предупреждение о переполнении;
- рекомендации по оптимизации.
