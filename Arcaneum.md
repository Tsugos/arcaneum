# Что такое Arcaneum

Arcaneum — это модульная платформа для взаимодействия с языковыми моделями (LLM) и ИИ-персонажами, созданная с приоритетом на автономность, гибкость и полный контроль пользователя над своими данными.

Проект разрабатывается как Progressive Web App (PWA), одинаково удобное для использования на настольных компьютерах, планшетах и мобильных устройствах.

Arcaneum не привязан к одному поставщику моделей, одному формату персонажей или одному сервису. Любая подсистема должна быть заменяемой без необходимости переписывать ядро приложения.

---

# Цели проекта

Основные цели Arcaneum:

- предоставить единый клиент для работы с различными AI-провайдерами;
- обеспечить гибкую систему управления персонажами;
- реализовать развитую систему памяти и Lorebook;
- предоставить мощный конвейер формирования промптов;
- поддерживать генерацию текста, изображений и голосовых функций;
- гарантировать локальное хранение пользовательских данных;
- обеспечить долгосрочную масштабируемость проекта.

# Структура документации

Документация разделена на независимые документы.

Каждый документ описывает отдельную подсистему.

Рекомендуемый порядок чтения:

1. PROJECT_CONTEXT
2. PROJECT_VISION
3. PROJECT_RULES
4. TECH_STACK
5. ARCHITECTURE
6. Остальные документы

---

# Документация — источник истины

Любая реализация должна соответствовать документации.

Если код противоречит документации, приоритет имеет документация до тех пор, пока архитектурное решение не будет официально пересмотрено.

---

# Правила работы агента

Перед началом реализации агент обязан:

- изучить всю документацию;
- определить затрагиваемые подсистемы;
- проверить совместимость нового решения с существующей архитектурой;
- предложить архитектурное решение;
- получить подтверждение пользователя;
- только после этого приступать к реализации.

# Основной принцип

Arcaneum создается не как набор функций, а как платформа, которую можно развивать в течение многих лет без переписывания ядра.
