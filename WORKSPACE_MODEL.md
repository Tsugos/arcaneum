# WORKSPACE_MODEL

## Workspace

Workspace является контейнером верхнего уровня.

Все данные пользователя принадлежат Workspace.

---

# Workspace содержит

- Persona Library
- Sessions
- Story Library
- Lorebooks
- Memory Storage
- World States
- Images
- Voice Assets
- User Profile
- Templates
- Plugins
- Themes
- Settings
- Backups

---

# Изоляция

Workspace полностью автономен.

Данные одного Workspace никогда не должны зависеть от другого.

---

# Экспорт

Экспорт Workspace должен восстанавливать проект в том же состоянии, в котором он был сохранён.

После импорта пользователь не должен замечать разницы между исходным и восстановленным состоянием.

---

# Версионирование

Каждый Workspace имеет собственную версию схемы.

При открытии старых Workspace приложение обязано выполнять миграции автоматически.

---

# Автосохранение

Все изменения фиксируются автоматически.

Пользователь не обязан вручную сохранять прогресс.

---

# Резервное копирование

Workspace поддерживает:

- полную резервную копию;
- инкрементальную резервную копию;
- ручные снимки (Snapshots);
- автоматические контрольные точки.

Все операции выполняются локально по умолчанию.
