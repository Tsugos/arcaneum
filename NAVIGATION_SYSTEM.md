# NAVIGATION_SYSTEM

## Главная идея

Навигация должна быть максимально незаметной.

Пользователь должен думать о своей истории, а не о том, где находится нужная функция.

---

# Основные способы навигации

- боковая панель;
- вкладки;
- глобальный поиск;
- Command Palette;
- горячие клавиши;
- контекстные меню.

---

# Command Palette

Arcaneum предоставляет единое окно команд.

Пользователь может быстро:

- открыть Persona;
- переключить Workspace;
- найти Story;
- изменить модель;
- выполнить инструмент;
- открыть настройки.

---

# Поиск

Поиск является глобальным.

Он может находить:

- Persona;
- Story;
- Session;
- Lorebook;
- Memory;
- Assets;
- Settings.

---

# Горячие клавиши

Любое часто используемое действие должно иметь сочетание клавиш на настольной версии.

На мобильной версии должны существовать альтернативные способы выполнения тех же действий.
