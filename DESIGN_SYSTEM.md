# DESIGN_SYSTEM

## Цель

Arcaneum использует единый дизайн-язык.

Новые элементы интерфейса обязаны использовать существующие компоненты.

---

# Основные принципы

Минимализм.

Высокая читаемость.

Небольшое количество цветов.

Акцент на содержимом, а не на декоративных элементах.

---

# Компоненты

Все элементы строятся из базовых компонентов:

- Button;
- Card;
- Dialog;
- Panel;
- List;
- Tree;
- Input;
- Menu;
- Tabs;
- Toast;
- Modal.

Создание новых компонентов допускается только при отсутствии подходящего существующего решения.

---

# Скругления

Во всём приложении используются единые значения радиусов и отступов.

---

# Анимации

Анимации должны быть короткими.

Их задача — помогать пользователю понимать изменения интерфейса, а не украшать приложение.

---

# Иконография

Используется единый набор иконок.

Запрещается смешивать разные стили.
