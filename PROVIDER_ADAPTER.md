# PROVIDER_ADAPTER

## Назначение

Provider Adapter отделяет внутреннюю архитектуру Arcaneum от особенностей конкретных AI Provider.

Prompt Pipeline никогда не взаимодействует напрямую с API.

---

# Почему это необходимо

Каждый AI Provider имеет собственные особенности:

- формат сообщений;
- системные инструкции;
- параметры генерации;
- ограничения;
- поддерживаемые функции.

Provider Adapter преобразует универсальное представление Arcaneum в формат, ожидаемый выбранным провайдером.

---

# Основные обязанности

- преобразование Prompt Context;
- преобразование параметров генерации;
- поддержка мультимодальности;
- обработка ответов;
- унификация ошибок;
- определение возможностей модели.

---

# Capability Detection

Каждая модель должна описывать свои возможности.

Например:

- максимальный контекст;
- поддержка изображений;
- поддержка функций;
- поддержка JSON;
- поддержка русского языка;
- поддержка Roleplay.

Эти данные используются другими подсистемами.

---

# Независимость

Добавление нового Provider Adapter не должно требовать изменения Prompt Pipeline или Domain Layer.
