# RELATIONSHIP_EDITOR

## Назначение

Relationship Editor управляет отношениями между Persona.

---

# Типы отношений

Друг.

Враг.

Союзник.

Родственник.

Наставник.

Ученик.

Работодатель.

Подчинённый.

Любовный интерес.

Нейтральный.

---

# Направленность

Отношения могут быть односторонними.

Например:

Персонаж A доверяет персонажу B.

Персонаж B подозревает персонажа A.

---

# Динамика

Отношения могут изменяться автоматически на основе Story Engine и Memory Engine.

---

# История

Каждое изменение отношения сохраняется.

Пользователь может увидеть, почему отношение изменилось.
