# PROJECT_CONTEXT

---

# Назначение проекта

Arcaneum — персональная AI-платформа нового поколения, объединяющая возможности современных AI-клиентов, систем работы с персонажами и инструментов создания контента.

Главная задача проекта — предоставить пользователю полный контроль над взаимодействием с языковыми моделями без искусственных ограничений.

Проект создается исключительно для личного использования.

Он не является коммерческим продуктом и не предназначен для публичного распространения.

---

# Ключевая идея

Arcaneum должен стать "операционной системой" для работы с искусственным интеллектом.

Модели являются лишь одним из компонентов.

В центре проекта находится пользователь, а все остальные системы работают как независимые сервисы вокруг него.

---

# Что входит в систему

В рамках проекта будут реализованы:

- AI Provider Layer;
- Character System;
- Prompt Pipeline;
- Memory Engine;
- Lorebook Engine;
- Image Generation;
- Voice Processing;
- Plugin System;
- Backup Manager;
- Theme Manager;
- Settings Manager;
- Model Manager;
- Chat Engine;
- File Storage.

Каждая система является самостоятельным модулем.

---

# Что не является целью

Arcaneum не ставит своей целью:

- создание социальной сети;
- публичное размещение персонажей;
- коммерциализацию;
- привязку к одному AI-сервису;
- копирование конкретного существующего продукта.

---

# Целевая аудитория

Основной пользователь проекта — его автор.

Поэтому приоритет отдается удобству, гибкости и функциональности, а не массовому рынку.

---

# Долгосрочное видение

Проект должен оставаться актуальным независимо от появления новых моделей или AI-провайдеров.

Ни одна архитектурная часть не должна предполагать существование только одного поставщика моделей или только одного формата данных.

Любая подсистема должна заменяться независимо от остальных.
