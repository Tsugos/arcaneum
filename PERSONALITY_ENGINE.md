# PERSONALITY_ENGINE

## Назначение

Personality Engine отвечает за описание внутреннего характера Persona.

---

# Основные компоненты

Черты характера.

Ценности.

Страхи.

Цели.

Мотивация.

Слабости.

Сильные стороны.

Привычки.

Манера речи.

Любимые темы.

Нелюбимые темы.

---

# Поведение

Каждая черта может иметь уровень выраженности.

Например:

Спокойствие

■■■■■■□□□□

Юмор

■■□□□□□□□□

Агрессия

■■■■□□□□□□

Это облегчает восприятие пользователем и позволяет использовать значения в Prompt Pipeline.

---

# Противоречия

Система допускает существование противоречивых черт характера.

Например:

Добрый.

↓

Безжалостный к врагам.

Такие комбинации считаются нормальными.
