# MEMORY_ENGINE

## Назначение

Memory Engine отвечает за сохранение, извлечение и подготовку информации, необходимой для поддержания долгосрочной последовательности взаимодействия.

Память является самостоятельной подсистемой и не зависит от конкретной модели или AI Provider.

---

# Цель

Память существует не для хранения всей истории сообщений.

Её задача — предоставлять модели только ту информацию, которая действительно необходима в текущий момент.

---

# Основные компоненты

Memory Engine состоит из нескольких независимых подсистем:

- Short-Term Memory;
- Long-Term Memory;
- Summary Engine;
- Retrieval Engine;
- Memory Ranking;
- Memory Storage.

Каждая из них имеет собственную ответственность.

---

# Short-Term Memory

Хранит недавний контекст общения.

Используется для обеспечения непрерывности диалога.

Не предназначена для долговременного хранения.

---

# Long-Term Memory

Содержит устойчивые факты, которые должны сохраняться между сессиями или на протяжении длительных историй.

Примеры:

- отношения между персонажами;
- значимые события;
- постоянные привычки;
- важные открытия.

---

# Главный принцип

Память не должна превращаться в архив всей переписки.

Каждая запись должна иметь ценность для будущего взаимодействия.

Накопление нерелевантной информации ухудшает качество генерации и увеличивает расход контекста.
