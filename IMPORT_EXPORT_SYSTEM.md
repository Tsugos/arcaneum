# IMPORT_EXPORT_SYSTEM

## Назначение

Import/Export System обеспечивает переносимость данных Arcaneum.

Пользователь должен иметь возможность перенести свои данные между устройствами без потери функциональности.

---

# Принцип

Внутренний формат Arcaneum является каноническим.

Все внешние форматы преобразуются во внутреннюю модель через адаптеры.

---

# Поддерживаемые операции

- импорт Persona Package;
- экспорт Persona Package;
- импорт Workspace;
- экспорт Workspace;
- импорт отдельных Story;
- экспорт Story;
- импорт Lorebook;
- экспорт Lorebook.

---

# Совместимость

Поддержка сторонних форматов реализуется отдельными адаптерами.

Изменение стороннего формата не должно затрагивать ядро приложения.

---

# Проверка

Перед импортом выполняется:

- проверка версии;
- проверка структуры;
- проверка целостности;
- проверка зависимостей.

При обнаружении несовместимости пользователь получает подробное описание проблемы.

---

# Экспорт

Экспортированные данные должны содержать информацию о версии схемы и совместимых версиях Arcaneum.
