# QUERY_ENGINE

## Назначение

Query Engine предоставляет единый механизм поиска данных во всех подсистемах Arcaneum.

Подсистемы не должны напрямую обращаться к IndexedDB или другим хранилищам.

Все запросы проходят через Query Engine.

---

# Возможности

Поддерживаются:

- фильтрация;
- сортировка;
- полнотекстовый поиск;
- поиск по тегам;
- поиск по связям;
- пользовательские запросы.

---

# Принципы

Запросы должны быть декларативными.

Подсистема описывает, какие данные ей нужны, а не каким образом их получать.

---

# Кэширование

Часто используемые запросы могут кэшироваться.

Кэш не должен нарушать актуальность данных.

---

# Индексация

Все крупные коллекции должны иметь индексы.

Запрещается выполнять полный перебор коллекций без необходимости.

---

# Будущее развитие

Query Engine должен позволять заменить локальное хранилище без изменения остальных подсистем.
