# THEME_ENGINE

## Назначение

Theme Engine управляет внешним видом Arcaneum.

---

# Возможности

Поддерживаются:

- светлая тема;
- тёмная тема;
- системная тема;
- пользовательские темы.

---

# Цветовая система

Все цвета задаются через дизайн-токены.

Компоненты не должны использовать фиксированные значения цветов.

---

# Пользовательские темы

Пользователь может создать собственную тему без изменения исходного кода.

---

# Акцентный цвет

Workspace может иметь собственный акцентный цвет.

Это позволяет визуально различать проекты.

---

# Совместимость

Темы не должны влиять на бизнес-логику приложения.

Изменение темы не должно требовать перезагрузки.
